砂川闘争年表

From the development of Sunagawa Shinden to the return of Tachikawa Air Base, through articles already in this archive / 砂川新田の開発から立川基地返還まで、アーカイブ収録の記事でたどる年表

この年表は、アーカイブに収録された「砂川平和ひろば」の公開記事、とくに砂川年表（1609～1977）をもとに、出来事を並べたものです。新しい歴史叙述ではなく、既存記事への案内です。年表そのものは各年の原典・文献にあたって確認してください。

This chronology is an index compiled from public articles already preserved here, mainly the 砂川年表（1609～1977）. It is navigation, not a new history.

砂川の前史（1609〜1954）

  1. 1609

    砂川村の開発願

    前史 / Before the struggle

    村山郷岸村の村野家により、幕府に砂川村の開発願が出されました。

  2. 1629

    砂川新田の開発開始

    前史 / Before the struggle

    砂川新田の本格的な開発が始まりました。

  3. 1654

    玉川上水の開通

    前史 / Before the struggle

    玉川上水が開通しました。

  4. 1736

    砂川新田が砂川村に

    前史 / Before the struggle

    砂川新田（砂川一番〜八番、現在の一番町〜幸町）が砂川村となりました。

  5. 1889

    砂川村の成立

    前史 / Before the struggle

    町村制施行により独立行政村として砂川村が成立。甲武鉄道（現JR中央線）も開通しました。

  6. 1922

    陸軍立川飛行場の創設

    前史 / Before the struggle

    陸軍立川飛行場が創設され、以後数回にわたり拡張されました。

  7. 1945

    終戦と米軍の進駐

    前史 / Before the struggle

    太平洋戦争の終結後、立川基地にも米軍が進駐して接収しました。

  8. 1950

    朝鮮戦争と警察予備隊

    前史 / Before the struggle

    朝鮮戦争が勃発し、警察予備隊が設置されました。

  9. 1951

    講和条約と安保条約

    前史 / Before the struggle

    サンフランシスコ講和条約と日米安全保障条約が調印され、翌年発効しました。

  10. 1954

    砂川町の成立

    前史 / Before the struggle

    砂川村は町制を施行し、砂川町となりました。

砂川闘争（1955〜1956）

  1. 1955年5月4日

    拡張案の非公式通告

    砂川闘争 / Struggle

    東京調達局立川事務所長が宮崎町長宅を訪れ、米軍立川基地の拡張案が非公式に通告されました。

  2. 1955年5月6日

    基地拡張反対同盟の結成

    砂川闘争 / Struggle

    拡張予定地域（砂川四番・五番地区）の関係者が「基地拡張反対同盟」を結成しました。

  3. 1955年5月9日

    拡張計画の正式通告

    砂川闘争 / Struggle

    東京調達局より立川基地拡張計画が正式に通告されました。

  4. 1955年5月12日

    砂川町議会の反対決議

    砂川闘争 / Struggle

    砂川町議会は基地拡張反対を全員一致で決議し、全町議が闘争委員となりました。

  5. 1956年10月1日〜14日

    強制立ち入り測量と激突

    砂川闘争 / Struggle

    測量隊と武装警官が強制立ち入り測量に出て、連日（とくに12・13日）激突が続きました。

  6. 1956年10月14日

    測量の一時中止

    砂川闘争 / Struggle

    測量の一時中止が発表されました。翌日、阿豆佐味天神社で国民総決起大会が開かれ、4000名が集結しました。

運動の経緯をひろば自身が説明した記事は、「砂川闘争」について（日本語版）やAbout Sunagawa-Toso (Struggle)にあります。詳しくは砂川闘争入門へ。

砂川事件と伊達判決（1957〜1959）

  1. 1957

    砂川事件

    事件 / Incident

    デモ隊の一部が基地内に立ち入ったとして検挙され、刑事特別法違反で起訴されました。これが「砂川事件」です。

  2. 1959年3月30日

    伊達判決

    判決 / Judgment

    立川地方裁判所の伊達秋雄裁判長が、米軍基地の存在を憲法違反として被告全員に無罪を言い渡しました。

  3. 1959

    跳躍上告による判決破棄

    判決 / Judgment

    検察の跳躍上告により、伊達判決は最高裁判所で破棄されました。

事件と判決の解説は砂川事件とはと伊達判決とはへ。裁判の流れは国賠訴訟年表にあります。

その後（1960〜1977）

  1. 1960

    新日米安全保障条約の発効

    その後 / Aftermath

    新日米安全保障条約が発効しました。

  2. 1964

    ベトナム戦争の勃発

    その後 / Aftermath

    ベトナム戦争（トンキン湾事件）が勃発しました。

  3. 1968

    滑走路延長計画の中止

    その後 / Aftermath

    米軍は滑走路延長計画の中止を発表しました。

  4. 1972

    沖縄返還

    その後 / Aftermath

    沖縄が返還されました。

  5. 1973

    立川基地全面返還の決定

    その後 / Aftermath

    米軍は関東計画に基づき立川基地の全面返還を決定しました。この前年、陸上自衛隊が強行移駐していました。

  6. 1977

    立川基地の返還

    その後 / Aftermath

    立川基地が返還されました。
